# Campus Pulse — Discover What Students Are Up To

## Feature Overview

Campus Pulse is a campus-wide activity discovery feature that transforms CampusVerse RPG into more than just a productivity application. It acts as a digital activity layer for the entire college, allowing students to discover verified academic, sports, esports, club, and event participation across campus.

Instead of showing personal tasks or private goals, Campus Pulse highlights meaningful public campus involvement, helping students network, find teammates, and stay connected with what's happening around them.

---

## Problem It Solves

In most colleges, students participate in hackathons, sports tournaments, clubs, volunteering, and competitions, but there is no single platform where others can discover these activities.

Campus Pulse solves this by providing a searchable profile of verified campus involvement while respecting student privacy.

**Student = Player**

**Campus = Game World**

**Campus Pulse = Activity Discovery System**

---

## Key Features

### Student Search

Students can search for other students, teams, clubs, or organizations using a universal search bar.

Search results display:

* Student name and avatar
* Current level and title
* Primary interests and activity categories
* Recently active status
* Quick access to the student's public activity profile

This allows users to instantly discover active members of the campus community.

---

### Campus Activity Profile

Every student has a public Campus Activity Profile focused on verified campus participation instead of social content.

The profile includes:

* Current Level and RPG Title.
* Current Involvements (clubs, teams, events, hackathons).
* Recent Activity Timeline.
* Verified achievements and participation history.
* Public badges and titles earned through campus activities.

The timeline automatically updates whenever a student participates in an official event or completes a verified public quest.

---

### Currently Involved Section

Campus Pulse automatically detects ongoing campus involvement.

Examples include:

* Active Hackathons.
* Esports Teams.
* Coding Clubs.
* Sports Teams.
* Cultural Clubs.
* Event Volunteer Programs.

Students do not manually edit this section. It is generated from verified registrations and memberships.

### Verified Activities

Campus Pulse supports a verification system managed through the Admin Panel.

Verified activities include:

* Tournament participation.
* Event volunteering.
* Competition winners.
* Club memberships.
* Hackathon participation.
* Academic achievements.

Only verified activities receive a verification badge, preventing fake achievements from appearing on public profiles.

### Privacy Controls

Campus Pulse is designed with privacy first.

**Visible Public Information**

* Verified campus activities.
* Club memberships.
* Team participation.
* Public badges and titles.
* Official achievements.
* Current campus involvement.

**Hidden Information**

* Private tasks.
* Personal goals.
* Notes.
* Study schedule.
* Unverified achievements.
* Sensitive personal information.

Students can choose:

* Campus Public.
* Limited Visibility.
* Private Profile.

## Backend Workflow

Campus Pulse works automatically through the existing CampusVerse RPG backend.

1. Student joins an event, club, or team.
2. Participation is stored in the database.
3. Admin verifies the participation (or it is auto-verified for official events).
4. Activity is added to the student's Activity History.
5. Campus Pulse reads recent verified activities.
6. Public profile updates automatically.

No manual profile maintenance is required.

## Why Campus Pulse is Unique

Unlike traditional college portals that only list events, Campus Pulse shows **who is actively participating across campus**.

Unlike social media, it focuses only on meaningful campus involvement.

Unlike LinkedIn, it represents a student's journey inside the college ecosystem through academics, sports, esports, clubs, volunteering, and events.

Campus Pulse transforms CampusVerse RPG into both a gamified productivity platform and a campus networking platform where students can discover opportunities, teammates, and communities through verified activity history.
